«Трекер откликов» — некоммерческий проект для портфолио: сервис, где можно вести список вакансий, на которые вы откликнулись. Ниже — какие данные он использует и зачем.

Какие данные мы получаем

  • При входе через Google — ваше имя, адрес электронной почты и ссылку на аватар. Пароль от Google сервису недоступен.
  • Данные, которые вы вводите сами — компании, должности, ссылки на вакансии, зарплатные вилки, даты, заметки и статусы откликов.
  • Технические данные сессии — IP-адрес и тип браузера сохраняются вместе с сессией входа, чтобы вы могли видеть и защищать свой аккаунт.

Как данные используются

Только для работы сервиса: чтобы узнать вас при входе и показать ваши вакансии. Данные не продаются, не передаются третьим лицам для рекламы и не используются для аналитики или обучения моделей.

Использование информации, полученной через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Где хранятся данные

Сайт и сервер размещены на Vercel, база данных — в Neon (PostgreSQL), серверы в США.

Cookie

Используется только cookie сессии входа — без неё сервис не узнает вас при следующем визите. Рекламных и аналитических cookie нет.

Удаление данных

Вы можете выйти из аккаунта в любой момент. Чтобы удалить аккаунт и все связанные с ним данные, создайте запрос в репозитории проекта на GitHub. При удалении аккаунта удаляются и все ваши вакансии. Также можно отозвать доступ сервиса в настройках аккаунта Google.

Изменения

Если политика изменится, новая версия появится на этой странице с обновлённой датой. Вопросы — через GitHub.
